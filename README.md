# ASCII Art Generator

Converte imagens em arte ASCII usando Python.

## Requisitos

```bash
pip install Pillow
sudo apt install python3-tk  # Linux
```

## Como usar

```bash
python3 main.py
```

1. Selecione a imagem na janela que abrir
2. O resultado aparece no terminal
3. Escolha onde salvar o `.txt`

## Estrutura

```
├── main.py               # Ponto de entrada
├── image_processing.py   # Manipulação de imagem
├── ascii_converter.py    # Conversão para ASCII
└── file_manager.py       # Seleção e salvamento de arquivos
```
